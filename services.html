Services

개발 서비스

회로 설계, PCB 아트웍, 샘플 제작, 펌웨어, 디버깅, 양산, 인증 지원. 제품이 되기까지 필요한 전자 개발의 전 과정을 수행합니다. 필요한 단계만 의뢰하셔도 됩니다.

01

회로 설계

Circuit Design

제품이 해야 할 일을 시스템 블록도로 먼저 정리한 뒤 MCU와 핵심 부품을 고릅니다. 성능만이 아니라 재고와 단종 위험, 목표 단가, 인증 시험까지 함께 보고 양산 가능한 회로를 설계합니다.

전원 · 파워

  • AC-DC SMPS, DC-DC 컨버터, LDO 전원부
  • 리튬 배터리 충전·보호·잔량 표시
  • 히터 출력 제어(PWM·위상·SSR·트라이액)
  • 고전압 모듈·대전류 부하 구동

구동 · 제어

  • BLDC·스텝·DC·서보 모터 구동
  • 펌프·팬·솔레노이드·밸브·릴레이 구동
  • 펠티어(TEC) 온열·쿨링 제어
  • 정전류 LED·UV 램프 구동

센서 · 아날로그

  • 온도·습도·압력·무게(로드셀) 계측
  • 공기질(가스·VOC·먼지)·유량·수위 감지
  • IMU, 엔코더, 홀 센서, 전류·전압 측정
  • 신호 증폭·필터, ADC 입력 설계

특수 출력 회로

  • RF 고주파(3 MHz, 7 MHz 등) 출력부
  • EMS·갈바닉·이온 미세전류 출력
  • 초음파·진동·LED 테라피 구동
  • 2.4 GHz 등 무선 RF 모듈 적용
02

PCB 아트웍

PCB Layout

회로를 설계한 엔지니어가 아트웍까지 직접 진행합니다. 회로의 의도가 패턴에 그대로 반영되고, 기구 외곽·커넥터 위치·방열 조건을 맞춰 한 번에 조립되는 보드를 만듭니다.

설계 범위

  • 양면~다층 PCB 아트웍
  • 소형·고밀도 SMD 부품 배치
  • 대전류·고전압 패턴 설계
  • 기구 외곽·홀·커넥터 위치 반영

품질 고려

  • 전원·그라운드 구성, 노이즈·EMI 대책
  • 발열 부품 배치와 방열 패턴
  • 생산·조립을 고려한 DFM 설계

산출물

  • 거버·드릴 데이터
  • BOM, 부품 좌표(Pick & Place) 데이터
  • 조립도, 3D STEP 데이터
03

샘플 제작

Prototype

설계 데이터로 PCB 제작, 부품 구매, 실장까지 진행해 실물 샘플을 만듭니다. 받은 보드를 그대로 쓰실 수 있도록 기본 동작 확인을 마친 뒤 전달합니다.

제작

  • PCB 제작·부품 구매·SMT 실장 진행
  • 소량 샘플 조립과 리워크
  • 케이블·하네스 구성

확인

  • 전원·기본 동작 확인 후 전달
  • 수정 사항 반영한 리비전 샘플 제작
  • 필요 시 목업과 함께 조립(부가 서비스)
04

펌웨어 개발

Firmware

하드웨어를 설계한 팀이 펌웨어를 작성하기 때문에 회로와 코드 사이에서 생기는 문제를 빠르게 찾고 고칩니다. 동작 시퀀스, 예외·안전 처리, 사용자 설정 저장까지 실제 사용 환경을 기준으로 구현합니다.

제어

  • BLDC 정밀 제어(토출량 ±0.05 g 수준)
  • PID 온도·속도 제어, 히터·펌프·팬 제어
  • 센서 신호 처리와 검출 알고리즘
  • 파라미터 저장, 과열·과전류 보호

통신

  • UART, RS-232, RS-485, Modbus RTU/TCP
  • CAN, EtherCAT, Mechatrolink-II, Ethernet
  • BLE, Wi-Fi, LoRa, 2.4 GHz RF, MQTT
  • I²C, SPI, USB

플랫폼

  • STM32, ABOV, Microchip PIC, AVR
  • Nordic nRF, ESP32, Arduino
  • EdgeTX 등 오픈소스 펌웨어 포팅

사용자 인터페이스

  • TFT·HMI LCD, OLED, 문자 LCD, FND
  • 정전식 터치·버튼·엔코더 입력
  • LED·부저·진동 피드백
05

디버깅 · 검증

Debugging & Validation

오동작의 원인은 회로, 펌웨어, 부품, 사용 환경 어디에나 있을 수 있습니다. 측정 장비로 신호를 직접 확인하고 회로와 코드를 함께 분석해 근본 원인을 찾아 고칩니다. 다른 업체가 개발한 보드의 문제 분석도 맡습니다.

디버깅

  • 오실로스코프·로직 분석기 기반 신호 분석
  • 회로·펌웨어 동시 원인 분석
  • 타사 개발 보드·펌웨어 문제 분석과 수정

검증

  • 기능·통신·전원 시험
  • 장시간 동작·에이징 시험
  • 노이즈·온도 등 사용 환경 점검
06

양산 지원

Mass Production

샘플이 동작하는 것과 양산되는 것은 다른 문제입니다. 부품 수급, 생산성, 검사 방법을 미리 반영해 양산 단계의 재설계를 줄이고, 양산 이후 생기는 문제에도 대응합니다.

양산 준비

  • 양산용 아트웍·BOM 정리, 대체 부품 검토
  • 생산 검사 지그·검사 프로그램 제작
  • 생산처 기술 대응, 초도 생산 품질 확인

양산 이후

  • 불량 원인 분석과 개선
  • 펌웨어 업데이트·기능 개선
  • 부품 단종 시 대체 설계
07

인증 지원

Certification

인증은 설계 단계에서 미리 준비할수록 비용과 기간이 줄어듭니다. 시험 항목을 고려해 회로와 아트웍을 검토하고, 시험 중 문제가 생기면 원인을 분석해 대책을 설계합니다.

인증 대응

  • KC 전기용품·전자파 인증 대응
  • 해외 인증 대응(일본·러시아 인증 경험)
  • 인증 시험 대비 설계 검토

시험 지원

  • 시험 부적합 시 원인 분석·대책 설계
  • 인증용 회로도·부품 리스트 등 기술 자료 준비

  • 3D 기구 설계와 내부 부품 배치

목업 제작

손에 쥐어 보고 판단할 수 있도록 실물 목업을 만듭니다. 외관 확인용 목업부터 보드를 넣어 실제로 동작하는 기능 시제품까지 제작합니다.
